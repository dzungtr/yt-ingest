# CONTEXT — yt-workflow

## Glossary

**Single-URL mode** — A CLI invocation providing a literal YouTube URL as a positional argument (e.g., `fetch <url>` or `run <url>`). Produces output on stdout, writes no disk artifacts unless `--output` is given. Contrast with batch mode.

**Batch mode** — A CLI invocation providing `--file <path>` pointing to a file with multiple YouTube URLs. Always writes cache files and notes to disk. Unchanged from the original pipeline behavior.

**Agent mode** — Invoked via the `--agent` flag. Signals that a coding agent (not a human) is calling the CLI. In agent mode, `run` outputs only the raw transcript text to stdout — no extract, no synthesis, no DeepSeek API call. The agent's own LLM handles summarization. `--agent` is a no-op on `fetch` (since `fetch` already outputs raw transcript text).

**Transcript text** — Concatenated plain text from all transcript segments, formatted as `[mm:ss] text` lines, suitable for consumption by an agent's LLM.

**Study note** — The markdown output produced by the `extract` step: per-video structured notes generated by an LLM from the transcript, then merged and rendered via Jinja2 template.

**Synthesis** — The cross-video analysis produced by the `synthesize` step: cross-cutting themes, contradictions, complementary ideas, and unified synthesis generated by an LLM from multiple study notes.

## Gem pipeline

**Gem** — A near-verbatim, timestamped transcript fragment that must survive into the study note: causal laws, conditional/bet structures, definitional asides, embedded quotes carrying factual anchors, and closing predictions. _Avoid_: highlight, key point, takeaway.

**Gem mining** — The recall-first per-chunk pass that extracts candidate gems before writing begins. Over-inclusive by design; an unneeded gem costs a checklist line, a missed gem is lost forever.

**Gem-guided writing** — The draft-writing pass that produces a study note with the chunk's gems as a must-include checklist.

**Verification** — The independent, per-gem judgment of whether a gem's idea survived into the finished note, anchored to a transcript excerpt rather than the note's own self-description. Emits covered / missing / inapplicable verdicts. _Avoid_: validation, self-check.

**Patch** — The single insert-only repair that folds missing gems into the finished note without lengthening it.

**Persistence report** — The per-video record of every gem verdict, reason, and retry outcome. _Avoid_: audit log.
